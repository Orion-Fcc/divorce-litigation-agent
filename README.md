# 婚讼管家 · 离婚诉讼智能顾问

一个独立运行的智能体，覆盖离婚诉讼全流程指导：程序指引、证据清单、财产分割逻辑、抚养权准备、文书框架。基于 DeepSeek API 驱动。

**v2.1 起统一为 Python 架构**：所有业务逻辑（法律库检索、自主学习、LLM 代理、文件解析）都在 Python 后端（`python_app/`）中；浏览器版与桌面版都只是它的前端外壳，**双击即用，首次运行自动完成 Python 环境初始化**（自动装依赖 → 自动生成 config.json → 自动构建法律库）。

## 本地目录结构（就三个东西，别的不需要管）

| 文件/文件夹 | 用途 |
|---|---|
| `启动婚讼管家-浏览器版.bat` | 双击使用【浏览器版】 |
| `婚讼管家-桌面版/婚讼管家.exe` | 双击使用【桌面版】 |
| `python_app/` | 全部核心代码（改功能改这里，两个版本共用） |

### 方式一：浏览器版

双击 **`启动婚讼管家-浏览器版.bat`**。脚本自动探测本机 Python（PATH → py 启动器 → 常见安装目录），并自动完成：

1. 检查/安装 Python 依赖（pip install -r requirements.txt）
2. 首次运行自动生成 `config.json`（生成后用记事本填入你的 DeepSeek Key 并重启）
3. 首次运行自动构建法律库（从政府/法院官网抓取 9 部法律官方文本，约 1-2 分钟）
4. 启动本地服务并自动打开浏览器

之后每次双击都直接进入应用（已初始化的步骤自动跳过）。

### 方式二：Windows 桌面应用

双击 **`婚讼管家-桌面版/婚讼管家.exe`**。桌面壳启动时自动拉起同目录的 `python_app` 后端，并显示初始化进度闪屏——**首次运行同样自动完成依赖安装、配置生成与法律库构建**，之后秒开。关闭应用时自动结束后端。

要求：本机装有 Python 3.9+（PATH 中可用 `python` 或 `py -3`，或装在 `%LOCALAPPDATA%\Programs\Python\` 下，均可被自动发现）。

## 核心能力

- **本地法律库**：内置 18 部现行有效婚姻家庭相关法律/司法解释/规范性文件的**官方文本**（民法典婚姻家庭编与继承编、婚姻家庭编司法解释一二、继承编解释一、涉彩礼规定、人身安全保护令规定、反家庭暴力法、妇女权益保障法、未成年人保护法、老年人权益保障法、家庭教育促进法、母婴保健法、婚姻登记条例、婚姻登记工作规范、诉讼费用交纳办法、民事诉讼法、刑法婚姻家庭相关条文），全部抓取自政府/法院/检察院官网并记录来源链接；提问时自动检索相关条文注入回答，**引用法条必注明出处**
- **法律依据卡片**：每轮回答下方可展开查看本次引用的条文原文及官方来源
- **自主学习**：每轮有效对话结束后，服务端把会话要点**脱敏**蒸馏为经验存入本地经验库（上限 500 条），后续对话自动检索复用，越用越贴合你的场景；经验仅存本机
- **法律库自动迭代**：法律文本超过 7 天自动在后台重新抓取更新，跟踪法律修订
- **当前时间感知**：每次对话自动注入当前日期，冷静期/上诉期等期限推算以真实日期为基准
- **当事人视角（自动判断）**：Agent 自己从对话判断提问人是男方/女方/孩子方/律师/第三方，按其视角组织建议；无需手动选择（涉及子女一律以子女最佳利益优先）
- **材料解析全支持**：图片（视觉模型 OCR）、PDF、Word、文本均可上传解析
- **法律库浏览与条文搜索**：界面内可直接浏览 9 部法律、搜索条文、点开官方来源核对原文

## 高级/手动方式（可选）

```bash
cd python_app
pip install -r requirements.txt
copy config.example.json config.json   # 填入你的 API Key
python tools/build_legal_db.py         # 手动构建法律库
python main.py                         # 启动（自动开窗口/浏览器）
python main.py --no-window --port 7891 # 指定端口只起服务
python main.py --auto-init             # 手动触发自动初始化
```

说明：

- `config.json` 存放 DeepSeek Key 和视觉模型 Key，已加入 .gitignore，不会上传
- 数据（经验库、学习状态）存在 `python_app/data/`，仅在本机
- 重新抓取法律文本：`python tools/build_legal_db.py`；校验：`python tools/build_legal_db.py --check`

## 功能

- 离婚诉讼全流程指引（协议/诉讼离婚选择、立案、调解、开庭、上诉、执行）
- 五大类证据清单梳理（感情破裂 / 财产 / 债务 / 过错 / 抚养能力）
- 财产分割分析（共同财产界定、分割原则、高频争议点）
- 抚养权与抚养费准备（年龄分档规则、抚养费计算区间）
- 文书结构框架（起诉状 / 答辩状 / 证据目录）
- 法律库浏览与条文搜索（官方来源可点开核对）
- 多会话管理、会话导出、一键清空（二次确认）

## 材料解析

点击输入框左侧回形针上传材料，解析后自动交给 DeepSeek 分析：

| 材料类型 | 支持情况 |
|---|---|
| 图片（合同/文书/截图照片） | 支持。服务端配置视觉模型（智谱 GLM-4V-Flash 免费，或阿里通义千问 VL），先提取文字再分析 |
| TXT / MD / CSV / JSON | 支持，直接读取内容 |
| PDF / Word(docx) | 支持，由 Python 后端本地解析（pypdf / python-docx），文件不离开你的电脑 |

- 图片上传前自动压缩到 1600px 以内；文档/文本超过 2 万字自动截断
- 扫描件 PDF 无文字层，请拍照后用图片方式上传
- 所有解析均在本地或你配置的服务商 API 完成，不经过任何第三方中转

## 内置合规边界

- 只提供法律信息参考，不输出「包赢」式结论，结尾固定附风险提示与法律依据清单
- 拒绝协助隐匿/转移财产、伪造债务、非法取证、抢夺藏匿子女等违规请求
- 涉及家暴优先提示人身安全保护令、报警、妇联 12338、法律援助 12348

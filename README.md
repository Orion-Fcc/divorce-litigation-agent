# 律衡 · 你的全领域法律顾问

一个本地运行的法律顾问：分析劳动争议、合同纠纷、民间借贷、侵权赔偿、房产物业、消费维权等各类法律问题，也擅长婚姻家事（离婚、抚养、财产分割、继承）。内置**全部现行有效的宪法、法律、法律解释、行政法规、监察法规、司法解释**官方文本，回答时自动检索引用、注明出处。

浏览器版和桌面版共用一个核心（`python_app/`），双击即用。首次运行会自动装好依赖、生成配置文件，之后每次直接进入。

## 本地目录结构（就三个东西，别的不需要管）

| 文件/文件夹              | 用途                    |
| ------------------- | --------------------- |
| `启动律衡-浏览器版.bat`   | 双击使用【浏览器版】            |
| `律衡-桌面版/律衡.exe` | 双击使用【桌面版】             |
| `python_app/`       | 全部核心代码（改功能改这里，两个版本共用） |

### 方式一：浏览器版

双击 **`启动律衡-浏览器版.bat`**。脚本自动探测本机 Python（PATH → py 启动器 → 常见安装目录），并自动完成：

1. 检查/安装 Python 依赖（pip install -r requirements.txt）
2. 首次运行自动生成 `config.json`（生成后填入你的模型配置并重启：默认 DeepSeek，也支持 Ollama / vLLM 等自主部署的 OpenAI 兼容端点）
3. 法律库随程序附带（约 1500 部现行有效法律文件）；仅当法律库缺失/为空时才联网构建，全量收录约需 30-60 分钟
4. 启动本地服务并自动打开浏览器

之后每次双击都直接进入应用（已初始化的步骤自动跳过）。

### 方式二：Windows 桌面应用

双击 **`律衡-桌面版/律衡.exe`**。桌面壳启动时自动拉起同目录的 `python_app` 后端，并显示初始化进度闪屏——**首次运行同样自动完成依赖安装与配置生成**，之后秒开。关闭应用时自动结束后端。

要求：本机装有 Python 3.9+（PATH 中可用 `python` 或 `py -3`，或装在 `%LOCALAPPDATA%\Programs\Python\` 下，均可被自动发现）。

## 核心能力

- **完整法律库**：内置全部**现行有效**的宪法、法律、法律解释、行政法规、监察法规、司法解释（约 1500 部、数十万条），全部来自国家法律法规数据库（flk.npc.gov.cn，全国人大常委会办公厅维护）及政府/法院官网，每条法条带条号、正文、施行日期、官方来源链接；提问时自动检索相关条文注入回答，**引用法条必注明出处**
- **混合检索 RAG**：倒排索引（关键词/条号精确匹配）+ 本地向量语义检索（bge-small-zh 嵌入模型，纯本地推理）双路召回，条号零幻觉、口语提问（如「借钱不还」「被辞退」）也能命中对应法条
- **法律依据卡片**：每轮回答下方可展开查看本次引用的条文原文及官方来源
- **Agent Memory（长期记忆）**：SQLite 数据库三层记忆——语义记忆（对话中自动提取当事人事实，脱敏去重，跨会话保留）、情节记忆（有法条依据的经验沉淀，带质量护栏）、会话记忆（会话摘要）；回答时自动检索相关记忆结合你的实际情况，界面可查看/一键清空
- **自主 LLM 接入**：对话模型可配置为 DeepSeek、Ollama、vLLM 或任意 OpenAI 兼容端点（`config.json` 的 llm_provider / llm_base_url / llm_model），无需代理、数据直连
- **自主学习（带护栏）**：只有当回答给出了「有法条依据的确定结论」时才沉淀经验——拒绝协助类、不确定、纯闲聊的回答一律不学；经验脱敏后存本地（上限 500 条），注入时明确标注「仅供参考，以现行法条为准」
- **法律库自动迭代**：法律文本超过 30 天自动后台全量刷新，跟踪法律修订
- **当前时间感知**：每次对话自动注入当前日期，诉讼时效/上诉期/冷静期等期限推算以真实日期为基准
- **咨询方视角（自动判断）**：Agent 自己从对话判断提问人是当事人/律师/第三方，按其视角组织建议；无需手动选择（涉及未成年人一律以子女最佳利益优先）
- **材料解析全支持**：图片（视觉模型 OCR）、PDF、Word、文本均可上传解析
- **法律库浏览与条文搜索**：界面内可直接浏览全部法律（按类别分组、可筛选）、搜索条文、点开官方来源核对原文

## 技术实现

- **RAG 检索增强生成（混合检索）**：不把法律文本直接塞进模型，而是每次提问先做一轮本地检索——查询词先做口语同义词扩充（如「冷静期→三十日」「借钱→借款」「辞退→解除劳动合同」），双路召回：**倒排索引**（二元组词元，条号/法律名精确匹配，毫秒级）+ **向量语义检索**（本地 bge-small-zh 量化 ONNX 嵌入模型，ONNX Runtime 推理，numpy 余弦相似度，模型约 24MB 首次自动下载），按 (法律, 条号) 去重合并后注入系统提示词。回答有法条依据、条号准确、可追溯来源；向量模型缺失时自动降级为纯关键词检索，不影响使用。
- **本地法律知识库**：全部法律原文以结构化 JSON 存储，每条法条带条号、正文、施行日期、官方来源链接；构建脚本调用国家法律法规数据库接口获取清单与官方 Word/PDF 全文，按「第 X 条」切分（支持「第 X 条之一」），支持断点续传、增量更新与全量刷新（`tools/build_all_laws.py`）。
- **Agent Memory（SQLite 三层记忆）**：语义记忆（LLM 从对话提取当事人事实，强制脱敏 + 内容指纹去重，上限 2000 条）、情节记忆（经验蒸馏，带质量护栏：回答须含法条/依据信号、不得含不确定表述才沉淀）、会话记忆（会话更新时间与摘要）；检索注入时关键词 + 向量双路召回，注入块明确标注「以当事人最新表述为准」。旧版 experience.jsonl 自动迁移。
- **提示词工程**：系统提示词固定四块——角色与能力（全领域法律顾问，婚姻家事为强项）、工作流程与输出格式（结论 + 分点 + 法律依据清单 + 风险提示）、咨询方视角自动判断、引用与合规红线（禁止虚构法条、禁止协助转移财产/伪造债务/非法取证）。
- **自主 LLM 接入**：对话模型端点可配置（llm_provider 预设 deepseek / ollama / vllm / openai / custom + llm_base_url / llm_model / llm_key），任何 OpenAI chat/completions 兼容服务均可接入，密钥可留空（本地部署）；视觉模型同样可换（智谱 GLM-4V-Flash / 通义千问 VL）。
- **当前时间注入**：模型自身没有实时时钟，服务端每次请求都注入当前日期，用于诉讼时效、上诉期、仲裁时效等期限的准确推算。
- **多模态解析**：图片接视觉模型 OCR；PDF / Word 由本地库（pypdf / python-docx）解析，文件不出本机。
- **流式输出**：前后端用 SSE（Server-Sent Events）逐字推流，前端带超时保护，网络中断会自动恢复、已生成内容不丢失。
- **架构**：一个本地 HTTP 服务（Python 标准库 http.server，外部依赖仅 requests / numpy / onnxruntime）+ 一个单文件前端（原生 JS，无框架）+ 一个 Electron 桌面壳；三者共用同一份核心代码。

## 高级/手动方式（可选）

```bash
cd python_app
pip install -r requirements.txt
copy config.example.json config.json   # 填入模型配置（见下）
python main.py                         # 启动（自动开窗口/浏览器）
python main.py --no-window --port 7891 # 指定端口只起服务
python main.py --auto-init             # 手动触发自动初始化
```

模型配置（`config.json`，支持自主部署，无需代理）：

```json
{
  "llm_provider": "deepseek",          // deepseek / ollama / vllm / openai / custom
  "llm_base_url": "",                  // custom 时填写，如 http://127.0.0.1:11434/v1（Ollama）
  "llm_key": "sk-xxx",                 // 本地部署可留空
  "model": "deepseek-chat"             // 对话模型名，如 qwen2.5:7b
}
```

- Ollama：`llm_provider` 填 `ollama`（默认连 http://127.0.0.1:11434/v1），或 `custom` + 你自己的地址
- vLLM / LM Studio / 任何 OpenAI 兼容服务：`custom` + `llm_base_url`（vLLM 默认 http://127.0.0.1:8000/v1）
- 流式对话、经验蒸馏、记忆提取共用同一个端点

法律库工具（`python_app/tools/`）：

```bash
python tools/build_legal_db.py            # 构建精编库（民法典全本 + 婚姻家事相关）
python tools/build_legal_db.py --check    # 校验精编库完整性
python tools/build_all_laws.py            # 全量收录全部现行有效法律（断点续传）
python tools/build_all_laws.py --refresh  # 全量刷新（跟踪法律修订）
python tools/build_all_laws.py --max 10   # 只处理前 10 部（联调测试）
```

说明：

- `config.json` 存放模型与视觉模型配置，已加入 .gitignore，不会上传
- 数据（Agent Memory 数据库、经验、向量索引）存在 `python_app/data/`，仅在本机
- 向量嵌入模型（bge-small-zh，约 24MB）首次使用时自动下载到 `python_app/models/`
- 法律库收录范围：宪法、法律、法律解释、行政法规、监察法规、司法解释（现行有效）；地方性法规数量过万且地域性强，暂未收录

## 功能

- 全领域法律咨询：民事 / 劳动 / 行政 / 刑事，判断问题类型、讲清规则与判断标准
- 程序与期限指引：立案、管辖、举证、开庭、上诉、执行流程要点与法定期限
- 证据指引：针对具体纠纷列出证据清单与合法收集方式
- 金额测算：赔偿标准、抚养费、工资基数、利息、诉讼费等公式与区间
- 文书结构框架（起诉状 / 答辩状 / 仲裁申请 / 协议文本）
- 法律库浏览与条文搜索（官方来源可点开核对）
- 多会话管理、会话导出、一键清空（二次确认）

## 材料解析

点击输入框左侧回形针上传材料，解析后自动交给对话模型分析：

| 材料类型                  | 支持情况                                                 |
| --------------------- | ---------------------------------------------------- |
| 图片（合同/文书/截图照片）        | 支持。服务端配置视觉模型（智谱 GLM-4V-Flash 免费，或阿里通义千问 VL），先提取文字再分析 |
| TXT / MD / CSV / JSON | 支持，直接读取内容                                            |
| PDF / Word(docx)      | 支持，由 Python 后端本地解析（pypdf / python-docx），文件不离开你的电脑    |

- 图片上传前自动压缩到 1600px 以内；文档/文本超过 2 万字自动截断
- 扫描件 PDF 无文字层，请拍照后用图片方式上传
- 所有解析均在本地或你配置的服务商 API 完成，不经过任何第三方中转

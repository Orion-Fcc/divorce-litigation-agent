# 婚讼管家 · 离婚诉讼智能顾问

一个独立运行的智能体，覆盖离婚诉讼全流程指导：程序指引、证据清单、财产分割逻辑、抚养权准备、文书框架。基于 DeepSeek API 驱动。

**v2.1 起统一为 Python 架构**：所有业务逻辑（法律库检索、自主学习、LLM 代理、文件解析）都在 Python 后端（`python_app/`）中；浏览器版与桌面版都只是它的前端外壳。

## 三种运行方式（同一套 Python 核心）

### 方式零：Python 版（推荐，功能最全）

```bash
cd python_app
pip install -r requirements.txt
copy config.example.json config.json   # 然后编辑填入你的 API Key
python tools/build_legal_db.py         # 首次构建法律库（约 1-2 分钟）
python main.py                         # 启动并自动打开窗口（无 pywebview 时自动用浏览器）
```

核心能力：

- **本地法律库**：内置 9 部现行有效婚姻家庭相关法律的**官方文本**（民法典婚姻家庭编、司法解释一/二、涉彩礼规定、反家庭暴力法、妇女权益保障法、未成年人保护法、婚姻登记条例、民事诉讼法），全部抓取自政府/法院官网并记录来源链接；提问时自动检索相关条文注入回答，**引用法条必注明出处**
- **法律依据卡片**：每轮回答下方可展开查看本次引用的条文原文及官方来源
- **自主学习**：每轮有效对话结束后，服务端把会话要点**脱敏**蒸馏为经验存入本地经验库（上限 500 条），后续对话自动检索复用，越用越贴合你的场景；经验仅存本机
- **法律库自动迭代**：法律文本超过 7 天自动在后台重新抓取更新，跟踪法律修订
- **当前时间感知**：每次对话自动注入当前日期，冷静期/上诉期等期限推算以真实日期为基准
- **当事人视角（自动判断）**：Agent 自己从对话判断提问人是男方/女方/孩子方/律师/第三方，按其视角组织建议；无需手动选择（涉及子女一律以子女最佳利益优先）
- **材料解析全支持**：图片（视觉模型 OCR）、PDF、Word、文本均可上传解析

说明：

- `config.json` 存放 DeepSeek Key 和视觉模型 Key，已加入 .gitignore，不会上传
- 数据（经验库、学习状态）存在 `python_app/data/`，仅在本机
- 重新抓取法律文本：`python tools/build_legal_db.py`；校验：`python tools/build_legal_db.py --check`

### 方式一：浏览器版

启动 Python 服务后用浏览器访问：

```bash
cd python_app
python main.py --no-window     # 启动后访问提示的 http://127.0.0.1:端口/
```

或指定固定端口：`python main.py --no-window --port 7891`，浏览器打开 http://127.0.0.1:7891/ 即可。

> 根目录的 `index.html` 即为该前端页面（与 `python_app/ui/index.html` 相同）。前端通过本机 HTTP 与 Python 后端通信，不再直接请求 DeepSeek，无跨域问题。

### 方式二：Windows 桌面应用

打包产物位于 `desktop/dist/婚讼管家-win32-x64/`，双击 `婚讼管家.exe` 运行。桌面壳启动时会自动拉起 `python_app` 后端（位于 exe 同级目录），就绪后加载页面；关闭应用时自动结束后端。

自行重新打包：

```bash
cd desktop
npm install
npm run pack      # 生成 dist/婚讼管家-win32-x64/
npm start         # 开发模式（自动寻找 ../python_app 并启动）
```

注意：exe 需要本机装有 Python 3.9+（PATH 中可用 `python` 或 `py -3`），且 `python_app` 文件夹与 exe 同级（含 `config.json` 与已构建的法律库）。

## 功能

- 离婚诉讼全流程指引（协议/诉讼离婚选择、立案、调解、开庭、上诉、执行）
- 五大类证据清单梳理（感情破裂 / 财产 / 债务 / 过错 / 抚养能力）
- 财产分割分析（共同财产界定、分割原则、高频争议点）
- 抚养权与抚养费准备（年龄分档规则、抚养费计算区间）
- 文书结构框架（起诉状 / 答辩状 / 证据目录）
- 法律库浏览与条文搜索（官方来源可点开核对）
- 多会话管理、会话导出、一键清空（二次确认）

## 材料解析

点击输入框左侧回形针上传材料，解析后自动交给 DeepSeek 分析：

| 材料类型 | 支持情况 |
|---|---|
| 图片（合同/文书/截图照片） | 支持。服务端配置视觉模型（智谱 GLM-4V-Flash 免费，或阿里通义千问 VL），先提取文字再分析 |
| TXT / MD / CSV / JSON | 支持，直接读取内容 |
| PDF / Word(docx) | 支持，由 Python 后端本地解析（pypdf / python-docx），文件不离开你的电脑 |

- 图片上传前自动压缩到 1600px 以内；文档/文本超过 2 万字自动截断
- 扫描件 PDF 无文字层，请拍照后用图片方式上传
- 所有解析均在本地或你配置的服务商 API 完成，不经过任何第三方中转

## 内置合规边界

- 只提供法律信息参考，不输出「包赢」式结论，结尾固定附风险提示与法律依据清单
- 拒绝协助隐匿/转移财产、伪造债务、非法取证、抢夺藏匿子女等违规请求
- 涉及家暴优先提示人身安全保护令、报警、妇联 12338、法律援助 12348

# 婚讼管家 · 离婚诉讼智能顾问

一个独立运行的智能体，覆盖离婚诉讼全流程指导：程序指引、证据清单、财产分割逻辑、抚养权准备、文书框架。基于 DeepSeek API 驱动。

## 两种运行方式

### 方式一：浏览器版（零安装）

直接双击打开 `index.html` 即可使用。

- 首次使用：点击右上角「设置」，填入 DeepSeek API Key（在 https://platform.deepseek.com 申请，新用户有免费额度）
- API Key 只保存在你自己浏览器的 localStorage 中
- 支持流式回复、多会话管理、会话导出（Markdown / JSON）

> 注意：浏览器模式下请求从浏览器直接发往 DeepSeek API。个别浏览器/网络环境可能出现跨域限制，若遇到连接失败，请改用桌面版。

### 方式二：Windows 桌面应用

打包产物位于 `desktop/dist/婚讼管家-win32-x64/`，双击其中的 `婚讼管家.exe` 即可运行，无需安装、无需浏览器。

自行重新打包：

```bash
cd desktop
npm install
npm run pack      # 生成 dist/婚讼管家-win32-x64/
npm start         # 开发模式直接运行
```

## 功能

- 离婚诉讼全流程指引（协议/诉讼离婚选择、立案、调解、开庭、上诉、执行）
- 五大类证据清单梳理（感情破裂 / 财产 / 债务 / 过错 / 抚养能力）
- 财产分割分析（共同财产界定、分割原则、高频争议点）
- 抚养权与抚养费准备（年龄分档规则、抚养费计算区间）
- 文书结构框架（起诉状 / 答辩状 / 证据目录）
- 多会话管理、会话导出、一键清空（二次确认）

## 材料解析（v1.1 新增）

点击输入框左侧回形针上传材料，解析后自动交给 DeepSeek 分析：

| 材料类型 | 支持情况 |
|---|---|
| 图片（合同/文书/截图照片） | 双端支持。需在设置中配置视觉模型（智谱 GLM-4V-Flash 免费，或阿里通义千问 VL），图片先由视觉模型提取文字再分析 |
| TXT / MD / CSV / JSON | 双端支持，直接读取内容 |
| PDF / Word(docx) | 仅桌面版支持（主进程本地解析，文件不离开你的电脑） |

- 图片上传前自动压缩到 1600px 以内；文档/文本超过 2 万字自动截断
- 扫描件 PDF 无文字层，请拍照后用图片方式上传
- 所有解析均在本地或你配置的服务商 API 完成，不经过任何第三方中转
